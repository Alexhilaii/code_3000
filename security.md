## Intended users
The intended users of this repository are my professor, TA, and myself, This repo is used to store and submit homework

## Security threats
Someone gaining unauthorized access could delete my work or change my answers to something inappropriate to affect my grade

## Security measure 
I use GitHub to track changes through version control but since this repo is small and only intended for submitting homework, I don't believe additional measures like a CODEOWNERS file are necessary
